## 예제4-1의 실행 결과 설명
1. %s는 공백 문자를 문자열의 끝으로 보고 홍길동까지 저장함.
2. %c는 공백 문자를 저장을 하기 때문에 M이 아니라 공백 문자를 저장함.
3. %d에는 M이 저장되어야 하지만 %d는 정수형을 저장하기 때문에 문자인 M을 저장하지 못하고 쓰레기값을 출력함.
4. 두번째 반복에서 %s에 M이 저장되고 %c는 공백 %d가 23을 저장함.
