# 실습과제1
| 수식 | 결과값 | 결과값의 자료형 |
| :--- | :--- | :--- |
| `&ch` | 100 | `char *` |
| `&in` | 101 | `int *` |
| `&db` | 105 | `double *` |
| `*&ch` | 'A' | `char` |
| `*&in` | 10 | `int` |
| `*&db` | 3.4 | `double` |

# 실습과제2
```
#include <stdio.h>
```
- 표준 입출력 헤더 파일 포함
```
int main(void)
```
- 메인 함수 시작
```
int a = -100;
```
- 정수형 변수 `a` 선언 및 `-100` 대입
```
char b = 'A';
```
- 문자형 변수 `b` 선언 및 `'A'` 대입
```
double c = 3.14;
```
- 실수형 변수 `c` 선언 및 `3.14` 대입
```
printf("int형 변수 a의 값은 : %d\n", *&a);
```
- `a`의 주소를 역참조한 값(`-100`)을 정수로 출력
```
printf("char형 변수 b의 값은 : %c\n", *&b);
```
- `b`의 주소를 역참조한 값(`'A'`)을 문자로 출력
```
printf("double형 변수 c의 값은 : %lf\n", *&c);
```
- `c`의 주소를 역참조한 값(`3.14`)을 실수로 출력
```
return 0;
```
- 프로그램 종료

# 실습과제3
```
#include<stdio.h>

int main(void)
{
	int* ptr = (int*)125; // ①
	*ptr = 10;
	printf("%d\n", *ptr);
	return 0;
}
```
- 1번 라인에서 강제 형변환이 사용된 이유<br>
`125`는 일반 정수(`int`) 데이터이고, `ptr`은 포인터 변수(`int*`)이다.
서로 다른 자료형 간의 대입을 위해 정수 `125`를 포인터 타입(`int*`)으로 변환하려고 강제형변환이 사용되었다.

- 코드 실행 시 오류가 발생하여 중단되는 이유<br>
`*ptr = 10;`은 `125`번지 주소의 메모리에 값 `10`을 저장하려는 코드이다.
그러나 `125`번지는 프로그램이 할당받지 않은 유효하지 않은 메모리 주소이다.
허용되지 않은 메모리 영역에 접근했으므로 운영체제에 의해 메모리 접근 위반에 오류가 발생하고 프로그램이 강제 중단된다.
