# 실습과제3
```
#include<stdio.h>

int main(void)
{
	int* ptr = (int*)125; // ①
	*ptr = 10;
	printf("%d\n", *ptr);
	return 0;
}
```
- 1번 라인에서 강제 형변환이 사용된 이유<br>
`125`는 일반 정수(`int`) 데이터이고, `ptr`은 포인터 변수(`int*`)이다.
서로 다른 자료형 간의 대입을 위해 정수 `125`를 포인터 타입(`int*`)으로 변환하려고 강제형변환이 사용되었다.

- 코드 실행 시 오류가 발생하여 중단되는 이유<br>
`*ptr = 10;`은 `125`번지 주소의 메모리에 값 `10`을 저장하려는 코드이다.
그러나 `125`번지는 프로그램이 할당받지 않은 유효하지 않은 메모리 주소이다.
허용되지 않은 메모리 영역에 접근했으므로 운영체제에 의해 메모리 접근 위반에 오류가 발생하고 프로그램이 강제 중단된다.
