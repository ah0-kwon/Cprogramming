# 실습과제1
## 구조체가 필요한 이유를 설명하라.
서로 다른 종류(자료형)의 데이터를 모아 하나로 묶어서 취급하면 사용과 관리가 매우 편리하기 때문이다.
## 배열과 공통점과 차이점을 설명하라
- 공통점 : 데이터들의 집합, 변수가 선언된 순서대로 연속된 메모리 공간에 할당
- 차이점 : 배열은 같은 종류의 데이터들만 묶을 수 있는 반면 구조체는 다른 종류의 데이터들을 묶을 수 있다.
## 기본자료형과 구조체의 차이를 설명하라.
기본자료형은 c언어에서 이미 정의된 자료형이고 구조체는 사용자가 직접 정의하는 자료형이다.
## 구조체 정의와 구조체 변수 선언의 의미를 각각 설명하라
- 구조체 정의 : 사용자가 새로운 자료형을 정의하는 일
- 구조체 변수 선언 : 구조체의 멤버 변수가 메모리 공간에 할당되는 것
