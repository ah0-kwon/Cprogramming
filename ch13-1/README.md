- 배열명의 의미를 설명하라.
  >배열 첫번째 요소의 주소
- 배열표현과 포인터(주소) 표현의 변환 공식을 설명하라.

  | 구분 | 배열표현 | 포인터(주소) 표현 |
  |------|----------|-------------------|
  | 배열요소의 값 | `a[i]` | `*(a+i)` |
  | 배열요소의 주소 | `&a[i]` | `a+i` |

- 배열의 첫번째 요소의 주소만 알면 모든 원소의 주소를 계산할 수 있다. 방법을 설명하시오.
  >배열 원소들은 메모리에 연속으로 배치되므로, 첫 번째 원소의 주소(시작 주소)에 인덱스 × 자료형의 크기를 더하는 산술 연산만으로 모든 원소의 주소를 계산할 수 있다.
- 배열의 첫번째 요소의 주소만 알면 모든 원소의 값를 계산할 수 있다. 방법을 설명하시오.

- 포인터에 대해 가능한 연산의 종류와 의미를 설명하라.

  | 연산 종류 | 설명 |
  | --- | --- |
  | 간접참조 연산 (`*`) | 포인터가 가리키는 주소에 저장된 값을 읽거나 쓰는 연산 |
  | 정수 덧셈 (`+`) | 포인터에서 정수 n을 더하면, 현재 주소에서 자료형 크기 × n 만큼 뒤로 이동 |
  | 정수 뺄셈 (`-`) | 포인터에서 정수 n을 빼면, 현재 주소에서 자료형 크기 × n 만큼 앞으로 이동 |
  | 증감 연산 (`++`, `--`) | 가리키는 자료형의 크기만큼 주소 이동 |

- 포인터 연산을 기존의 산술연산과 다르게 정의한 이유는 무엇일까?

# 실습과제3
## 1. 증감연산자 a++, ++a의 차이
  1. a++(후위 증감연산자): 현재 줄의 수식을 먼저 계산한 후, a의 값을 1 증가시킨다.
  2. ++a (전위 증감연산자): 현재 줄의 수식을 계산하기 전에 a의 값을 먼저 1 증가시킨 후, 그 결과를 수식에 사용한다.
## 2. 다음 코드의 문제점을 설명하고 포인터를 이용하여 문제를 해결하시오.
```
#include <stdio.h>
int main(void)
{
int a[] = { 10, 20, 30 }, i, sum = 0;
for (i = 0; i < 3; i++)
sum += *a++;
printf("sum:%d\n", sum);
return 0;
}
```

a는 포인터 변수가 아닌 배열명이다. 배열명은 주소값을 변경할 수 없는 상수이므로, a++와 같이 주소 값을 직접 변경하거나 대입할 수 없다.
