# 실습과제1
- C언어에서 문자를 메모리에 저장하는 방식에 대하여 설명하라(아스키 코드 참고)
  >컴퓨터는 숫자만 처리하기 때문에 문자를 숫자로 바꾼 아스키 코드를 사용하여 문자를 저장한다.
- 널문자의 용도를 설명하라
  >문자열의 끝을 나타내는 기호
- 메모리에 저장된 문자열의 끝을 찾는 방법을 설명하라
  >반복문을 사용하여 널문자가 나올 때까지 메모리를 한 칸씩 차례대로 읽는다.
- 문자열의 길이를 구하는 알고리즘을 설명하라
  >길이를 셀 변수를 선언한 다음 반복문을 사용하여 널문자를 만날 때까지 길이를 증가시키면 그 변수가 문자열의 길이가 된다.
