# 실습과제1
- 배열명의 의미를 설명하라.
  >배열 첫번째 요소의 주소
- 배열표현과 포인터(주소) 표현의 변환 공식을 설명하라.

  | 구분 | 배열표현 | 포인터(주소) 표현 |
  |------|----------|-------------------|
  | 배열요소의 값 | `a[i]` | `*(a+i)` |
  | 배열요소의 주소 | `&a[i]` | `a+i` |

- 배열의 첫번째 요소의 주소만 알면 모든 원소의 주소를 계산할 수 있다. 방법을 설명하시오.
  >
- 배열의 첫번째 요소의 주소만 알면 모든 원소의 값를 계산할 수 있다. 방법을 설명하시오.

- 포인터에 대해 가능한 연산의 종류와 의미를 설명하라.
  >간접참조 연산 (*)
  >포인터가 가리키는 주소에 저장된 값을 읽거나 쓰는 연산
  >정수 덧셈 (+)
  >포인터에서 정수 n을 더하면, 현재 주소에서 자료형 크기 × n 만큼 뒤로 이동
  >정수 뺄셈 (-)
  >포인터에서 정수 n을 빼면, 현재 주소에서 자료형 크기 × n 만큼 앞으로 이동
  > 증감 연산 (++, --)
  >가리키는 자료형의 크기만큼 주소 이동
- 포인터 연산을 기존의 산술연산과 다르게 정의한 이유는 무엇일까?
