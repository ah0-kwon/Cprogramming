# 실습과제1
- 배열명의 의미를 설명하라.
  >배열 첫번째 요소의 주소
- 배열표현과 포인터(주소) 표현의 변환 공식을 설명하라.

  | 구분 | 배열표현 | 포인터(주소) 표현 |
  |------|----------|-------------------|
  | 배열요소의 값 | `a[i]` | `*(a+i)` |
  | 배열요소의 주소 | `&a[i]` | `a+i` |

- 배열의 첫번째 요소의 주소만 알면 모든 원소의 주소를 계산할 수 있다. 방법을 설명하시오.
  >
- 배열의 첫번째 요소의 주소만 알면 모든 원소의 값를 계산할 수 있다. 방법을 설명하시오.

- 포인터에 대해 가능한 연산의 종류와 의미를 설명하라.
  >가능한 연산: 간접참조(*), 정수덧셈(+), 정수뺄셈(-), 증감(++, --)
  | 수식 (p: 포인터, n: 정수) | 의미 |
  | --- | --- |
  | p + n | p + n × (포인터가 가리키는 자료형의 크기) |
  | p - n | p - n × (포인터가 가리키는 자료형의 크기) |
  | p++ | p = p + (포인터가 가리키는 자료형의 크기) |
  | p-- | p = p - (포인터가 가리키는 자료형의 크기) |
