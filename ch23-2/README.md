## 구조체가 왜 필요한지 설명하시오.

## 공용체가 왜 필요한지 설명하시오.
하나의 메모리 공간을 2개 이상의 방식으로 접근 가능함
## 열거형이 왜 필요한지 설명하시오.
자료형(변수)이 가질 수 있는 값들을 원하는 대로 정의할 수 있는 자료형 -> 프로그램의 가독성 높임
