# 실습과제1
## 스트림과 버퍼의 역할을 각각 설명하시오.
- 스트림 : 입출력장치와 프로그램 사이의 데이터의 이동 경로 
- 버퍼 : 스트림 내부에 데이터를 임시로 저장하는 메모리 공간 
## 버퍼를 사용하여 얻는 장점과 단점을 모두 설명하시오. 
- 장점 : 
데이터를 버퍼에 모아서 한번에 전송할 수 있어서 효율적임
엔터키가 입력되기 전에 데이터를 수정할 수 있음 
- 단점 :
scanf를 이용하여 문자를 입력하고 출력할 때 줄바꿈이 남아있는다.
## 입력 버퍼에 데이터가 이미 존재할 때 scanf 함수를 호출한다면 어 떤 일이 발생하는가? 
사용자에게 입력을 받지 않고 입력 버퍼에 남아있는 데이터가 출력된다.
## 운영체제가 어떤 경우에 출력 버퍼의 데이터를 모니터로 출력하는 가? 
버퍼가 가득차거나 문장 입력이 완료될 때
## scanf함수와 printf함수 실행시 함수와 운영체제의 역할분담에 대하 여 설명하라. 
- scanf함수는 입력 버퍼에서 데이터를 읽어 오고 운영체제는 키보드에서 입력 버퍼로 전송하는 역할 
- printf함수는 출력 버퍼에 데이터를 출력하고 운영체제는 출력 버퍼에서 모니터로 전송하는 역할
