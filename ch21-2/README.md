# 실습과제1
## 표준 입출력 스트림을 접근하는 방법을 설명하라.
문자, 문자열 전용 입출력 함수에서 주소를 이용하여 스트림에 접근한다.
## 공백을 포함한 문자열을 입력 받을 때 사용가능한 함수는?
gets, fgets
## gets 함수사용시 가장 큰 문제점은 무엇인가?
배열의 크기를 초과하는 문자열을 입력시 실행 오류가 발생한다.
## fgets 함수 사용시 문제점은 무엇인가?
문자열의 길이가 지정한 크기보다 큰 경우 잘라서 저장한다.
## 널문자(‘\0’)와 널포인터(NULL)의 용도를 설명하시오.
- 널문자(‘\0’): 문자열의 끝
- 널포인터(NULL): 어떤 객체도 가리키지 않는 포인터
